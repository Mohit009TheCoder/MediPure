┌──────────────────────────────────────────────────────────────────────────────┐
│                          API ENDPOINTS MAP                                   │
└──────────────────────────────────────────────────────────────────────────────┘

AUTHENTICATION:
  POST   /register              → Register new user
  POST   /token                 → Login & get JWT token

PATIENT ENDPOINTS:
  GET    /doctors/search        → Search doctors by area/specialty
  GET    /doctors/{id}/slots    → Get available slots for doctor
  POST   /appointments/book     → Book an appointment
  GET    /patient/appointments  → Get patient's appointments

DOCTOR ENDPOINTS:
  POST   /doctor/slots          → Add availability slot
  GET    /doctor/slots          → Get doctor's slots
  GET    /doctor/appointments   → Get doctor's appointments

PROFILE ENDPOINTS:
  GET    /profile/me            → Get current user profile
  PUT    /profile/update        → Update user profile

FRONTEND ROUTES:
  GET    /                      → Landing page
  GET    /login                 → Login/Register page
  GET    /dashboard             → User dashboard
  GET    /profile               → Profile page
  GET    /privacy               → Privacy policy
  GET    /terms                 → Terms of service
  GET    /contact               → Contact page
